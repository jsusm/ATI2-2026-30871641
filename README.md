# Gestión de Servicios de transporte

## Propuesta de mi proyecto de ATI2

En mi trabajo actual trabajamos con proveedores de transporte para llevar a cavo los eventos y actividades que realizamos, hay algunos proveedores que son pequeños (trabajan con 2 conductores) y otros grandes que tienen una flota grande y con un gran catalogo de vehiculos, estos últimos serían el público objetivo de esta propuesta, un software que gestione su negocio, desde generar facturas, hasta planear y hacer seguimiento de rutas y conductores.
